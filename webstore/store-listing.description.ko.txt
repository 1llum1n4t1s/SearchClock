Google 검색 결과를 선택한 기간 안으로 좁혀 주는 Chrome 확장 프로그램입니다.
검색 결과 페이지에 표시되는 패널에서 그 자리에서 한 번의 클릭으로 기간을 바꿀 수 있습니다.
"기간 유지"를 켜 두면 다음 검색에도 같은 기간이 자동으로 적용됩니다.

■ 주요 기능

・검색 결과 옆에 패널 표시
  Google 검색 결과 페이지의 오른쪽(화면이 좁을 때는 화면 오른쪽 아래)에 기간 선택 패널이 표시됩니다.
  패널이 늦게 표시되어도 검색 결과의 위치가 밀리지 않으므로 잘못 누르는 일을 막아 줍니다.
  기간을 선택하면 그 기간으로 좁힌 검색 결과로 바로 전환됩니다.

・다양한 프리셋
  3시간 / 12시간 / 1일 / 3일 / 1주 / 1개월 / 3개월 / 6개월 / 1년 / 3년
  중에서 고를 수 있습니다. "끄기"를 선택하면 표시 중인 페이지의 기간 지정을 해제할 수 있습니다.

・2가지 동작 모드("기간 유지" 스위치)
  OFF(1회만·기본 설정): 선택한 기간은 그 검색에만 적용되며, 확장 프로그램은 다음 검색에 기간을 자동으로 붙이지 않습니다.
  "설정을 되돌리는 것을 잊어서 의도하지 않은 기간으로 검색하는" 일을 막아 줍니다.
  ON(유지): 스위치를 켠 시점의 기간을 저장하고 다음 검색에도 자동으로 적용합니다.
  스위치는 패널 아래쪽에 있습니다. 기간을 선택하지 않았을 때나 Google에서 프리셋에 없는 기간을 지정했을 때는 켤 수 없습니다.

・검색 전에 URL에 기간 추가
  유지 중에는 Chrome의 declarativeNetRequest를 사용하여 검색 요청 단계에서 URL에 기간 지정을 붙입니다.
  검색 결과를 불러온 뒤에 다시 불러오는 일은 없습니다.

・Google 검색 도구와의 연동(나중에 한 조작 우선)
  Google 검색 도구에서 기간을 바꾸면 "기간 유지"가 자동으로 해제됩니다.
  패널에서 기간을 선택하면 그 기간으로 전환합니다. 이미지 크기나 정렬 순서 등 기간 이외의 조건은 그대로 유지합니다.
  항상 "마지막에 조작한 쪽"이 우선합니다.

・확장 프로그램 아이콘
  아이콘을 클릭하면 Google을 새 탭에서 엽니다.
  유지 중에는 저장된 기간의 약어(1y / 1mo 등)를 배지에 표시하고, 1회만 모드일 때는 "·"를 표시합니다.

・라이트/다크 테마 지원
  Google의 라이트·다크 테마에 맞추어 패널의 색상이 바뀝니다.

・가볍고 개인정보 보호 중시
  사용하는 권한은 declarativeNetRequest, storage, 그리고 지원하는 Google 검색 도메인에 대한 접근뿐입니다.
  기간 설정은 Chrome에 저장되며, Chrome 동기화를 사용하는 경우 동기화 대상이 됩니다.
  자체 외부 서버로 데이터를 전송하거나 외부 글꼴을 불러오지 않습니다.

・지원하는 Google 검색
  google.com, google.co.jp 등 11개 Google 도메인의 검색 결과 페이지를 지원합니다.

・이런 분께 추천합니다
  - 최신 정보를 검색하려는 분: 오래된 글에 묻히지 않고 새로운 정보를 찾고 싶은 분
  - 기술자·개발자: 프로그래밍 정보는 최신성이 중요하므로 항상 최신 글을 검색하고 싶은 분
  - 뉴스·트렌드: 지금 화제가 되는 정보만 좁혀 보고 싶은 분

■ 사용 방법

1. Chrome 웹 스토어에서 설치합니다
2. Google 검색을 하면 검색 결과 오른쪽에 SearchClock 패널이 표시됩니다
3. 원하는 기간을 선택합니다(예: 1년). 그 기간으로 좁혀집니다
4. 다음 검색에도 같은 기간을 사용하려면 "기간 유지" 스위치를 켭니다
   (OFF로 두면 선택한 기간은 그 검색에만 적용됩니다)
5. Google 검색 도구에서 기간을 바꾸면 "기간 유지"가 자동으로 해제됩니다
