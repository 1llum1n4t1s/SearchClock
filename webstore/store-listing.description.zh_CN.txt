SearchClock 是一款 Chrome 扩展程序，可将 Google 搜索结果限定在您选择的时间范围内。
在搜索结果页显示的面板中，一键即可切换时间范围。
开启“保持时间范围”后，之后的搜索也会自动应用同样的时间范围。

■ 主要功能

・在搜索结果旁显示面板
  时间范围面板显示在 Google 搜索结果页的右侧（窗口较窄时显示在屏幕右下角）。
  即使面板延迟出现，搜索结果的位置也不会移动，可避免误点。
  选择时间范围后，页面会立即切换为限定该时间范围的搜索结果。

・丰富的预设
  可选择 3小时 / 12小时 / 1天 / 3天 / 1周 / 1个月 / 3个月 / 6个月 / 1年 / 3年。
  选择“关闭”，即可取消当前页面的时间范围。

・两种工作模式（“保持时间范围”开关）
  关闭（仅一次，默认）：所选时间范围只应用于这一次搜索，扩展程序不会在下次搜索时自动添加时间范围。
  可避免因忘记恢复设置而在不经意间使用了某个时间范围搜索。
  开启（保持）：保存开启开关时的时间范围，之后的搜索也会自动应用。
  开关位于面板底部。未选择时间范围时，或 Google 指定了预设之外的时间范围时，无法开启。

・搜索前将时间范围加入 URL
  保持期间，扩展程序使用 Chrome 的 declarativeNetRequest，在搜索请求阶段就把时间范围加入 URL。
  不会先加载搜索结果再重新加载。

・与 Google 搜索工具联动（以最后操作为准）
  在 Google 搜索工具中更改时间范围后，“保持时间范围”会自动关闭。
  在面板中选择时间范围后，会切换为该时间范围。图片尺寸、排序等时间范围以外的条件会保留。
  始终以“最后操作的一方”为准。

・扩展程序图标
  点击图标，会在新标签页中打开 Google。
  保持期间，徽章上显示所保存时间范围的缩写（1y / 1mo 等）；仅一次模式下显示“·”。

・支持浅色/深色主题
  面板配色会随 Google 的浅色、深色主题切换。

・轻量，注重隐私
  使用的权限只有 declarativeNetRequest、storage，以及对受支持的 Google 搜索域名的访问。
  时间范围设置保存在 Chrome 中；如果启用了 Chrome 同步，则会一并同步。
  不会向自有的外部服务器发送数据，也不会加载外部字体。

・支持的 Google 搜索
  支持 google.com、google.co.jp 等 11 个 Google 域名的搜索结果页。

・适合这些用户
  - 想搜索最新信息的用户：不被旧文章淹没，找到新的信息
  - 技术人员、开发者：编程信息讲求时效，始终搜索最新的文章
  - 新闻与热点：只想查看当下热门内容的用户

■ 使用方法

1. 从 Chrome 应用商店安装
2. 使用 Google 搜索后，搜索结果右侧会显示 SearchClock 面板
3. 选择所需的时间范围（例如：1年），搜索结果就会限定在该时间范围内
4. 想让之后的搜索也使用同样的时间范围时，开启“保持时间范围”开关
   （保持关闭时，所选时间范围只应用于这一次搜索）
5. 在 Google 搜索工具中更改时间范围后，“保持时间范围”会自动关闭
