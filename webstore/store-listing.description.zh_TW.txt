SearchClock 是一款 Chrome 擴充功能，可將 Google 搜尋結果限定在您選擇的時間範圍內。
在搜尋結果頁顯示的面板中，一鍵即可切換時間範圍。
開啟「保持時間範圍」後，之後的搜尋也會自動套用相同的時間範圍。

■ 主要功能

・在搜尋結果旁顯示面板
  時間範圍面板顯示在 Google 搜尋結果頁的右側（視窗較窄時顯示在畫面右下角）。
  即使面板延遲出現，搜尋結果的位置也不會移動，可避免誤按。
  選擇時間範圍後，頁面會立即切換為限定該時間範圍的搜尋結果。

・豐富的預設
  可選擇 3小時 / 12小時 / 1天 / 3天 / 1週 / 1個月 / 3個月 / 6個月 / 1年 / 3年。
  選擇「關閉」，即可取消目前頁面的時間範圍。

・兩種運作模式（「保持時間範圍」開關）
  關閉（僅一次，預設）：所選時間範圍只套用於這一次搜尋，擴充功能不會在下次搜尋時自動加上時間範圍。
  可避免因忘記還原設定而在不經意間使用某個時間範圍搜尋。
  開啟（保持）：儲存開啟開關時的時間範圍，之後的搜尋也會自動套用。
  開關位於面板底部。未選擇時間範圍時，或 Google 指定了預設以外的時間範圍時，無法開啟。

・搜尋前將時間範圍加入網址
  保持期間，擴充功能會使用 Chrome 的 declarativeNetRequest，在搜尋請求階段就把時間範圍加入網址。
  不會先載入搜尋結果再重新載入。

・與 Google 搜尋工具連動（以最後操作為準）
  在 Google 搜尋工具中變更時間範圍後，「保持時間範圍」會自動關閉。
  在面板中選擇時間範圍後，會切換為該時間範圍。圖片大小、排序等時間範圍以外的條件會保留。
  一律以「最後操作的一方」為準。

・擴充功能圖示
  點擊圖示，會在新分頁中開啟 Google。
  保持期間，徽章上顯示所儲存時間範圍的縮寫（1y / 1mo 等）；僅一次模式下顯示「·」。

・支援淺色/深色主題
  面板配色會隨 Google 的淺色、深色主題切換。

・輕量，注重隱私
  使用的權限只有 declarativeNetRequest、storage，以及對受支援的 Google 搜尋網域的存取。
  時間範圍設定儲存在 Chrome 中；如果啟用了 Chrome 同步，則會一併同步。
  不會向自有的外部伺服器傳送資料，也不會載入外部字型。

・支援的 Google 搜尋
  支援 google.com、google.co.jp 等 11 個 Google 網域的搜尋結果頁。

・適合這些使用者
  - 想搜尋最新資訊的使用者：不被舊文章淹沒，找到新的資訊
  - 技術人員、開發者：程式設計資訊講求時效，隨時搜尋最新的文章
  - 新聞與熱門話題：只想查看當下熱門內容的使用者

■ 使用方法

1. 從 Chrome 線上應用程式商店安裝
2. 使用 Google 搜尋後，搜尋結果右側會顯示 SearchClock 面板
3. 選擇所需的時間範圍（例如：1年），搜尋結果就會限定在該時間範圍內
4. 想讓之後的搜尋也使用相同的時間範圍時，開啟「保持時間範圍」開關
   （保持關閉時，所選時間範圍只套用於這一次搜尋）
5. 在 Google 搜尋工具中變更時間範圍後，「保持時間範圍」會自動關閉
