# SearchClock

Google検索結果を、選んだ期間内に絞り込めるChrome拡張機能です。

<img width="1280" height="800" alt="01-feature-overview-1280x800" src="https://github.com/user-attachments/assets/91d61064-b575-466a-ad3d-2c2af5024805" />


## 機能

検索結果ページのパネルから、その場で期間を選べます。

- **一回限り（デフォルト）** — 選んだ期間をその検索だけに適用し、次の通常検索には引き継ぎません。
- **期間を維持** — 次の検索にも期間を自動適用します。検索結果の読み込み後に再読み込みする処理はありません。
- **Google検索ツールとの連携** — Google側で期間を変更すると維持を解除します。パネルで期間を選ぶと、その期間へ切り替えます。画像サイズや並び順など、期間以外の条件は保持します。
- **拡張機能アイコン** — クリックでGoogleを新しいタブで開きます。維持中は保存した期間の短縮ラベルをバッジに表示し、一回限りでは `·` を表示します。
- **テーマ対応** — Googleのライト・ダークテーマに合わせて表示を切り替えます。

## プリセット

オフ / 3時間 / 12時間 / 1日 / 3日 / 1週間 / 1ヶ月 / 3ヶ月 / 半年 / 1年 / 3年

## 使い方

1. Chrome Web Storeで「SearchClock」を探してインストールします
2. Google検索すると、検索結果の上にSearchClockパネルが表示されます
3. プリセットチップから期間を選択（例: 1年）→ その期間で絞り込まれます
4. ヘッダ右端の「期間を維持」スイッチで挙動を切替:
   - **ON**: 現在選んでいる期間を、次の検索にも自動適用します
   - **OFF**: 次の通常検索には期間を自動適用しません（デフォルト）。現在ページの絞り込みは残ります
5. Google検索のツールで期間を変更すると、拡張機能は自動でオフになります

期間未設定、またはGoogle側でプリセットにない期間を選んでいる場合、「期間を維持」は有効にできません。先にパネルで期間を選んでください。すでに維持中の場合は、この状態でもOFFにできます。OFFにしても保存済みの期間設定は変わりません。「オフ」のプリセットを選ぶと、現在ページの期間指定を解除できます。

## 対応するGoogle検索

`www.google.com` / `www.google.co.jp` / `www.google.co.uk` / `www.google.ca` / `www.google.com.au` / `www.google.de` / `www.google.fr` / `www.google.es` / `www.google.it` / `www.google.co.kr` / `www.google.com.br` の検索結果ページに対応します。

## 権限

- **declarativeNetRequest** — Google検索URLに期間指定パラメータを自動付与
- **storage** — 期間と維持モードを保存します。設定はChromeの設定同期の対象になります
- **対応するGoogleドメインへのアクセス** — 検索URLへの期間適用と、検索結果ページへのパネル表示に必要です。権限は各ドメイン全体を対象としますが、検索への介入は `/search` に限定します

独自の外部サーバーへのデータ送信や、外部フォントの読み込みは行いません。

## 困ったとき

- **パネルが表示されない** — 対応ドメインの検索結果ページか、Chromeの拡張機能設定でSearchClockが有効になっているか確認し、ページを再読み込みしてください。Google側のページ構成によってはパネルを表示できない場合があります。
- **次の検索で期間が解除される** — 一回限りモードの動作です。期間を選んでから「期間を維持」をONにしてください。
- **アイコンと現在ページの期間が違う** — バッジは維持用の保存設定を示します。現在ページへ実際に適用されている期間は、検索結果上のパネルで確認してください。
